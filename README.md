chipdale
========

[<img alt="build status" src="https://img.shields.io/github/actions/workflow/status/thelissimus/chipdale/ci.yaml?branch=master&style=for-the-badge" height="20" />](https://github.com/thelissimus/chipdale/actions?query=branch%3Amaster)

CHIP-8 emulator based on the guide [Building a CHIP-8 Emulator [C++]](https://austinmorlan.com/posts/chip8_emulator/).

Implementing it in C and using [Frama-C](https://git.frama-c.com/pub/frama-c) for specs. Usage of [CBMC](https://github.com/diffblue/cbmc), Isabelle and/or Rocq is yet to be decided.
